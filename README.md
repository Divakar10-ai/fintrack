# FinTrack — Personal Finance Tracker

A lightweight, zero-dependency personal finance tracker built with Python.

FinTrack helps users record income and expenses, monitor spending, and manage
budgets through a simple and efficient command-line interface.

---

## ✨ Features

- 💰 Track income
- 💸 Record expenses
- 📊 Monitor financial activity
- 🎯 Manage budgets
- 🧾 Organize transactions
- 🧪 Automated tests
- ⚡ Zero external runtime dependencies
- 🐍 Built with Python

---

## 🛠️ Tech Stack

- **Language:** Python
- **Testing:** Python testing framework
- **Build & Packaging:** `pyproject.toml`
- **Version Control:** Git & GitHub
